# Actual project screenshots

These six filename slots are ready in `index.html` and do not change the existing sticky/stacked project cards.

- `monoflix.png` — screenshot from your **MonoFlix** website
- `freshmart.png` — **included**, captured from the actual FreshMart HTML/CSS that you uploaded (the example order row is sample data, not your database)
- `foodieandroid.png` — screenshot of your Android app running in an emulator
- `insurance-cost.png` — screenshot of your actual Streamlit dashboard
- `imdb-data-mining.png` — image of a graph/visualization you made in the real project
- `distributed-task-battle.png` — screenshot of actual running system/output or architecture diagram from that repository

Place each file in `assets/project-previews/` using the exact file name shown above. Keep images at roughly 16:9 or 4:3 aspect ratio. The preview automatically switches from the current illustration to your real screenshot when the file exists, and retains the illustration until then.

To capture your projects on Windows, run the project, press Windows+Shift+S, crop the window, and save as PNG. For Android, use Android Studio's emulator Screenshot button. Don't include passwords, names, or other private data in the shots.

The CSS and JavaScript for the portfolio are unchanged except for these screenshot slots and styling.
