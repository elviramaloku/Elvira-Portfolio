# Elvira Maloku — Portfolio

Personal portfolio featuring MonoFlix, FoodieAndroid, and Distributed Task Battle.

## Run locally

Open `index.html` in a browser or with VS Code Live Server.

## Deployment

Connect this repository to Netlify. For a static site, use the repository root as the publish directory and leave the build command empty.

## Project links

The Distributed Task Battle card currently links to the GitHub repositories tab. Replace it with the specific repository URL when available.
